# Level Map — Critical Path

```
 [storm exterior / antenna silhouette]
              │ visible landmark
      ┌───────▼────────┐
      │  AIRLOCK       │ spawn; dead status console
      └───────┬────────┘
              │ warm leak from office
      ┌───────▼────────┐
      │  DUTY OFFICE   │ read work order: fuse → breaker / 3-1-4
      └───────┬────────┘
              │ cable tray / red fuse-case landmark
      ┌───────▼────────┐
      │ SERVICE PASSAGE│ collect thermal fuse
      └───────┬────────┘
              │ warning stripe / red fault glow
      ┌───────▼────────┐
      │ POWER ROOM     │ fit fuse; reset breaker
      └───────┬────────┘
         security door unlocks and opens
      ┌───────▼────────┐
      │ TRANSMITTER    │ tune 3-1-4; press transmit; ending
      │ GALLERY        │
      └────────────────┘
```

There are no dead-end “extra rooms.” The office and passage establish the input/clue; the power room changes access; the gallery resolves the scenario. A restart always returns to airlock spawn and resets every state.
