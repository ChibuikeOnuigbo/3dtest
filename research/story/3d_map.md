# Current game 3D map (prototype)

The machine-readable coordinate map is [`3d_map.json`](./3d_map.json). It describes the
current source blockout only; it has not passed browser reachability/collision testing.
The player follows R1 arrival jetty → R2 keeper hall → R3 skylit Signal Court. From that
hub, R4 generator bay is gated by the first sentry, R5 radio workshop is gated by power,
and its lantern gallery gate opens after routing. The current map will be discarded if
asset evidence selects a better setting/complete environment.
