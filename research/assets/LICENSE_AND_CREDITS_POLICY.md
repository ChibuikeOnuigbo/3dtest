# License and credit policy

The release must contain a human-readable `CREDITS.md` and a machine-readable asset
registry before final QA. Each non-original asset gets: stable asset ID, title, creator,
original URL, exact license/link, source date, downloaded source file/hash, transformations,
where it is used, attribution text and review status. Original project-authored procedural
meshes/source still receive an “original work” registry entry to make provenance clear.

Allowed does not mean automatically approved. A legally compatible asset may still fail
visual coherence, performance, technical import, story function or accessibility. Assets
with unclear licensing are blocked. Kenney is categorically prohibited. No API key,
account-only media, paid file, authentication/session workaround or TLS/security bypass is
used to satisfy this ledger.
