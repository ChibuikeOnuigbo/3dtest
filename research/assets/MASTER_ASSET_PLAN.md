# Master asset plan — pre-download

No third-party file is selected yet. This plan prevents blind download/merging and gives
each required production role one accountable decision path.

| Object / reason | Room | Priority | Source/search route | Candidate | Selected | Licence / format / animation | Status |
|---|---|---:|---|---|---|---|---|
| Complete architectural backbone; determines room scale and visual language | Entire world | P0 | Sketchfab complete/modular environment search; original modelling fallback | SF small industrial scene, SF modular building kit | None | CC BY displayed; actual archive/format unverified | CANDIDATE discovery only |
| Wall/floor surface family; makes original geometry believable | All | P0 | Original-source PBR material pages, 3–5 matched materials | None downloaded | None | exact licence/texture dimensions pending | DISCOVERED |
| Door/console/generator/lens hero props; explain gameplay purpose | R1–R5 | P0 | Original models first; selective complete-kit parts only later | Existing original blockout meshes | Original procedural blockout | Original, simple mechanical transforms | INSPECTED prototype |
| Sentry/held pulse device; supports one finite obstacle | Signal Court | P1 | Original geometric design or one legal coherent model | None | Original prototype | no skeleton promised | INSPECTED prototype |
| Ambient/interaction audio | All | P1 | Procedural Web Audio for simple tones; legal individual audio sources only if needed | Current procedural cues | Current procedural cues | Original generated simple audio | INSPECTED prototype |
| Human characters/complex animation | None required by current short concept | P3 | Do not search until story requires it | None | None | none | REJECTED from current scope |

A candidate becomes `DOWNLOADED` only by a permitted normal download flow. It becomes
`INSPECTED` after archive/model/texture analysis, then `APPROVED` only after legal,
visual, scale, QA and performance checks. `REJECTED` candidates are never imported as a
“temporary” shortcut.
