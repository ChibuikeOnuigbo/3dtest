# threejs-liminality — per-asset intake record

## Inventory / candidate status

README references Sketchfab, Pixabay, TextureCan, Poly Haven and other CC media. Each named file/source needs per-item source/terms/material/scale/poly inspection; no aggregate conclusion authorizes them.

## Required per-asset record

Every possible file is a separate candidate. Before shipping, record source URL, creator, exact licence, preview inspection, format/validity, PBR maps/materials, UV/normals, polygon/texture cost, real-world scale, visual style/context, supported in-world placement and browser performance result.

**Decision:** no asset is accepted merely from repository membership. A weak/mismatched/unlicensed individual asset may be rejected while a strong, fully cleared asset can be approved.
