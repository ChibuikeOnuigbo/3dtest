# Recurring implementation lessons

1. **Evidence labels matter.** A clone, README assertion, build success, local unit test,
   test-file discovery or preview HTTP 200 is not visual/gameplay/browser proof.
2. **Source MIT ≠ asset license.** Every reference checkout has to be split into code and
   individual media provenance. An aggregate “CC0” README is an intake lead, not a credit
   ledger. A conflicting displayed license blocks use.
3. **One mission state.** Doors, objectives, HUD, audio and animation must react to the
   same transition. If a door can look open while collision is closed, it is a defect—not
   atmosphere.
4. **Blockout is production work.** Camera height, threshold width, collision and sightline
   decisions precede décor. A room earns props only after it has a reason, landmark,
   interaction, light plan and screenshot review.
5. **Small is stronger.** A complete five-space route with one tool and a real ending is
   more defensible than copied FPS2 scope, multiple maps, unreviewed weapons or networking.
6. **Never bypass security for research/QA.** The video and browser TLS failures are real
   blockers. No disabled certificate checks, forged frames or substituted “QA images.”
