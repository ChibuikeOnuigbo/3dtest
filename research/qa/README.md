# QA Evidence Index

Runtime logs are retained in the repository-level `qa/` directory as required for direct test commands:
- `qa/build.log` — build and deterministic QA output
- `qa/assets.log` — material validation report
- `qa/animation.log` — selected animation strategy validation
- `qa/playthrough.log` — Playwright implementation and blocked execution evidence
- `qa/performance.log` — measured static performance budget

The human-readable QA summary is `docs/qa-report.md`.
