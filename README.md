# 3dtest

This repository is being restarted as a research-first browser FPS project.

The active branch contains evidence-led studies of the Enari Engine and FPS2 references,
a source/license/performance gate for any third-party material, original technical map
and system diagrams, and a strict future Playwright QA rubric. No previous game concept,
world, implementation, asset selection, browser test result, or completion claim is
carried forward as authoritative.

Start with [research/README.md](./research/README.md) and
[docs/research/README.md](./docs/research/README.md).
